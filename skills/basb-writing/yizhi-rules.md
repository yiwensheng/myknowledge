# BASB 写作与知识复用（易知 · 写文章 / 蒸馏）

在遵守「只许用检索片段」的前提下，按第二大脑习惯组织产出（Tiago Forte / Building a Second Brain 要点本地化）。

## 写文章时（静默）

1. **思想群岛**：动笔前在内部从检索片段与蒸馏 Skills/Principle 抽出 5～8 条可复用观点/事实/判断，排顺序、找缝隙，再按体例展开；禁止对着空白主题硬编。
2. **不为完美笔记卡壳**：优先把片段用进正文；缺处写「待补充」，勿一次做成百科。
3. **指向成果**：文章本身是中间成果包；结构清晰以便日后提问/再写复用。
4. **禁止**：输出「群岛清单」「渐进摘要过程」等元叙述进正文；事实仍只来自检索。

## 蒸馏时（Memory / Skills / Principle）

1. **渐进加价值**：本次只提炼值得留下的一层；勿把可变数据写进 Skills。
2. **中间成果包**：Memory 收原料；Skills 收可独立复用的结构；Principle 收取舍底线——三者都是可再调用的包，不是归档坟墓。
3. **为未来自己**：Skills/Principle 标题与首句须让三个月后的自己不用上下文也能懂「为何留下」。
4. **靠近项目**：优先沉淀能服务正在写的文章、正在答的问题的范式，勿追求漂亮空分类。
