## 5. 预赛 Demo 脚本（3 分钟视频 / 现场 5 分钟）

### 开场旁白（15s）

> 一人公司不是缺 AI，是缺「只基于我自己的资料、越用越强」的第二大脑。这是易知。

### 镜头 1 · 进库（40s）

1. 打开易知 GUI →「导入资料」  
2. 拖入课程大纲 PDF + 粘贴/保存一篇竞品网页  
3. 展示资料库列表与索引状态（旁白：多格式统一进库，本地留存）

### 镜头 2 · 有据问答 + 拒答（50s）

1. **提问 A**（库内有据）：「按我库里的大纲，第一节课核心目标是什么？」→ 流式回答，指出引用片段  
2. **提问 B**（库内无据）：「某未入库机构的内部招生配额是多少？」→ **明确拒答/无依据**（旁白：不编造，这是一人公司敢用的前提）

### 镜头 3 · 产出回写（40s）

1. 「写文章」：主题「本周朋友圈招生短文」，体例选短文/营销稿  
2. 基于库内资料生成 → 确认定稿入库（旁白：产出回到大脑，而不是聊完就丢）

### 镜头 4 · 一人成军工具链（25s）

1. 快速切到 Skills 列表或 `yws skill list`（3s 即可）  
2. 或展示 Loop / 推演 Tab 一帧（旁白：工作流与自进化，把个人变成流水线）

### 镜头 5 · 电信平台绑定（20s）

1. 设置页展示 TokenHub 的 `API Base` / 模型名（可打码 Key）  
2. 旁白：推理走 TokenHub，批量重任务可上息壤；可上架智云 Store

### 结尾（10s）

> 易知：一人公司第二大脑。息壤育智，一人成军。

- [ ] 分辨率 ≥ 1080p，鼠标高亮  
- [ ] 拒答镜头必须保留（差异化）  
- [ ] 字幕：产品名「易知」+「TokenHub/息壤」各出现 ≥1 次

## 7. TokenHub / 息壤接入清单（参赛版本必做）

### 7.1 配置（不改代码也可先通）

易知已支持 OpenAI 兼容接口（见 `.env.example`）：

```env
MYKNOWLEDGE_LLM_API_BASE=<TokenHub 兼容 Base，通常含 /v1>
MYKNOWLEDGE_LLM_API_KEY=<赛事发放 Key>
MYKNOWLEDGE_LLM_MODEL=<TokenHub 上架模型名>
# 若 TokenHub 提供 embedding：
# MYKNOWLEDGE_EMBEDDING_API_BASE=
# MYKNOWLEDGE_EMBEDDING_MODEL=
```

GUI「设置」保存后热加载；或改 `.env` 后重启后端。

### 7.2 材料中必须出现的表述

- 对话/写作/入库分析：**TokenHub 推理**  
- 批量嵌入重建、长文档分析、夜间 Loop：**可调度息壤算力**（按赛事实际开通能力填写，勿虚报）  
- 用户知识正文：**本地优先，不经过授权服务器上传内容**（与现有授权设计一致）

### 7.3 验证步骤

1. 智云 Store 开通赛事资源，拿到 Base/Key/模型名  
2. 写入 `.env`，`yws ask "用一句话介绍易知"`（需库内有相关页或先 ingest 产品说明）  
3. 截图：设置中的 Base（打码 Key）+ 一次流式问答  
4. 记一笔成本：Token 用量或调用次数（复赛「成效」用）

### 7.4 可选代码增强（有余力再做）

- 设置页增加「TokenHub / 息壤」预设档（一键填 Base）  
- 关于页增加「息壤杯参赛版」角标与平台致谢  
- 调用日志面板：展示最近请求的 model / latency（路演加分）
