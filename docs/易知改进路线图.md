# 易知改进路线图

> 基于 2026-07 全面改进方案实施记录。每期验收标准见下文。

## 第一期 — 不再像死机（已完成）

- 统一任务中心 `[electron/renderer/jobs-ui.js](../electron/renderer/jobs-ui.js)` 轮询 upload / url / linked / index 任务
- 全局 Toast `[electron/renderer/toast.js](../electron/renderer/toast.js)`
- 导入页全局进度条 `#global-job-panel`
- 外联/上传/URL 防重复提交（`data-busy-scope` + `YizhiJobs.setBusy`）
- 断连重试 `#reconnect-banner`

**验收：** 提交长任务 1s 内见进度；完成后 Toast 提示；双击不重复提交。

## 第二期 — 大库不卡、索引可靠（已完成）

- `[lib/index_writer.py](../lib/index_writer.py)`：单写者锁 + debounce sync + 后台建索引
- `[lib/watcher.py](../lib/watcher.py)`：`defer_index=True` + 6s debounce `sync_all`
- `[lib/rag.py](../lib/rag.py)`：缺失索引时 lazy 返回空并后台构建；`rebuild_index` 加锁
- `[lib/index_jobs.py](../lib/index_jobs.py)` + `POST /api/index` 异步
- `[lib/rag_embed.py](../lib/rag_embed.py)`：query embed LRU 缓存；`completeness_pct` 统计
- 授权 middleware 60s TTL 缓存

**验收：** inbox 批量落盘合并索引；首问不因缺索引同步卡死；RAG 状态含 `index_building` 与向量完整度。

## 第三期 — 能抓准、能找到（已完成）

- 微信公众号专用抓取链 `[lib/url_fetch.py](../lib/url_fetch.py)` `_fetch_weixin` + 质量检测
- 资料库「外联来源」Tab + `GET /api/library/external`
- 「待整理」草稿队列 + `GET /api/maintenance/drafts`
- 设置页「能力检测」+ `GET /api/capabilities`

**验收：** 公众号入库标题非域名；外联 chunk 可在资料库浏览；草稿可点击跳转编辑。

## 第四期 — 产品化（已完成）

- 主 Tab `role=tablist` + 方向键切换 + `:focus-visible`
- 新手指引 backdrop 误触跳过已移除
- CLI：`yws url --async`、`yws jobs list`
- 非阻塞确认框 `[electron/renderer/confirm.js](../electron/renderer/confirm.js)` + `YizhiConfirm.ask`
- `app.js` 全面改用 `uiError` / `uiInfo` / `uiConfirm`（仅 fallback 保留原生 alert/confirm）
- FTS5 阈值评估 `[lib/rag_fts_eval.py](../lib/rag_fts_eval.py)`，`rag_status()` 含 `fts5_recommended`
- 四期自动验收 `[scripts/verify_improvement_phases.py](../scripts/verify_improvement_phases.py)`（退出码 0 = 全部通过）

**验收：** `python scripts/verify_improvement_phases.py` 四期全绿；删除/移除外联等操作用模态确认而非阻塞 alert。

**后续可选：** `app.js` 进一步 ES module 拆分（不影响当前验收）。

## 第五期 — 检索代数升级（已完成）

> 在 SQLite 栈上实现 FTS5+RRF、Contextual 嵌入、Wiki 链接扩展、受限 Agent 与评测 harness。

### Phase A — FTS5 / BM25 + RRF

- [`lib/rag_fts.py`](../lib/rag_fts.py)、[`scripts/migrate_rag_fts5.py`](../scripts/migrate_rag_fts5.py)
- hybrid 默认 RRF 融合；TF 扫描作 FTS 不可用时的回退
- `MYKNOWLEDGE_FTS5=1`（默认开）、`MYKNOWLEDGE_RAG_RRF=1`

### Phase B — Contextual + Rerank

- chunk `context_prefix`；embedding 用「标题 > 章节 + 正文」
- [`lib/rag_rerank.py`](../lib/rag_rerank.py) 可选 `/rerank` API；`MYKNOWLEDGE_RAG_COARSE_K=20`
- 设置页与能力检测已扩展

### Phase C — Wiki Links 多跳

- [`lib/rag_graph.py`](../lib/rag_graph.py)；`MYKNOWLEDGE_GRAPH_EXPAND=1`（默认开）
- scope 限定时禁用图扩展

### Phase D — 受限 Agent + 评测

- [`lib/rag_agent.py`](../lib/rag_agent.py)；`prepare_ask` 走 `search_enhanced`
- [`scripts/eval_rag.py`](../scripts/eval_rag.py)、[`scripts/verify_rag_phases.py`](../scripts/verify_rag_phases.py)
- `MYKNOWLEDGE_RAG_AGENT=0` 默认关

**验收：** `python scripts/verify_rag_phases.py` 全绿；升级后执行 `python scripts/migrate_rag_fts5.py`。

**部署：** 重启后端；存量库建议 migrate FTS + 按需重建索引以写入 `context_prefix`。
