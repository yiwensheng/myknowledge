## 一、环境准备（开发机，只需一次）

| 依赖 | 用途 | 安装方式 |
|------|------|----------|
| **Python 3.10+** | 构建时**整份拷贝**为可搬迁内置 Python（**禁止 venv**） | 系统已装即可 |
| **Node.js 18+** | 构建 Electron 依赖 | 系统已装即可 |
| **ImageMagick** | 生成 Inno 兼容 `.ico`（非 PNG 压缩） | `winget install ImageMagick.ImageMagick` |

### 安装 Inno Setup 6

**方式 A（推荐）**

```powershell
winget install --id JRSoftware.InnoSetup -e
```

**方式 B（winget 不可用时）**

1. 浏览器打开 https://jrsoftware.org/isdl.php ，下载 `innosetup-6.7.3.exe`
2. 执行：

```powershell
cd E:\app\Myknowledge
.\scripts\install-innosetup.ps1 -InstallerPath "下载路径\innosetup-6.7.3.exe"
```

安装后 ISCC 默认路径：`C:\Program Files (x86)\Inno Setup 6\ISCC.exe`

## 二、发版前检查

1. **改版本号**：编辑 `electron/package.json` → `version`（如 `2.1.0`）；安装包 exe 的 Windows 属性（文件说明 / 公司 / 文件版本）由 `scripts/installer/YizhiSetup.iss` 的 `VersionInfo*` 与 `AppVersion` 同步，**须重新执行 build-installer 后才会更新**。
2. **确认开发机 `.env`**：大模型/RAG 配置完整（会注入用户包，设置页不显示）
3. **确认 `license-server/.env`**：记下 `LICENSE_JWT_SECRET`（须与安装包注入值一致）
4. **（可选）预检授权服务**：

```powershell
cd E:\app\Myknowledge
.\scripts\run_commercial_preflight.ps1 `
  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -AdminKey "<LICENSE_ADMIN_KEY>" `
  -JwtSecret "<LICENSE_JWT_SECRET>"
```

## 三、完整构建（推荐）

在 PowerShell 中：

```powershell
cd E:\app\Myknowledge

# 0. 先构建 Electron（npm install + vendor 同步，含 d3 / 文件预览 / 编辑器）
.\scripts\build-electron.ps1

# 1. 再打安装包
.\scripts\build-installer.ps1 `
  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -JwtSecret "<LICENSE_JWT_SECRET 与 license-server/.env 一致>"
```

> `build-installer.ps1` 内部的 staging 仍会再跑一遍 `npm install`（在输出目录内，避免污染开发机路径）。**第 0 步**用于在开发树里先验证 Electron 与前端 vendor 完整，避免 staging 跑到一半才发现缺依赖。

### 脚本会做什么

1. 生成 **staging**（`dist\Yizhi-Staging-<版本>-<时间戳>/`）：可搬迁内置 Python、Electron、ffmpeg 等
2. **默认**额外构建 `runtime\yizhi-backend.exe`（PyInstaller onedir）；Electron 启动优先用之，`python\` 仍作 bootstrap/回退
3. **最小依赖**：Python 仅 `requirements-runtime.txt`；Electron 构建后删掉已同步到 `vendor/` 的 npm 包，只留 `electron`；并 prune 测试/文档/多余语言包
4. 排除开发机 wiki / 上传 / 对话库；初始化**空知识库**
5. 从开发机 `.env` 注入大模型到 `.env.user`（`MYKNOWLEDGE_HIDE_LLM_SETTINGS=1`）
6. 注入授权地址、JWT 密钥、更新检查 URL
7. 生成 `YizhiStart.bat` / `YizhiStart.vbs`（ASCII 启动器；探测 `runtime\` 或 `python\`）
8. 下载并打入 **VC++ Redist**（安装时缺则自动静默补装）
9. 生成易知图标、`latest.json` 更新清单
10. 调用 Inno Setup 编译安装包
11. **构建门禁**：`runtime\yizhi-backend.exe` 必须存在（除非 `-SkipBackendBinary`）；若 `python\pyvenv.cfg` 存在则失败

### 依赖分层（勿把可选库打进用户包）

| 文件 | 用途 |
|------|------|
| `requirements-runtime.txt` | **安装包唯一 pip 来源**（API + 文档导入 + Pillow/mutagen） |
| `requirements.txt` | 开发机 = runtime + OCR 等可选 |
| `requirements-optional.txt` | 说明用；playwright / 重工具勿进包 |
| `electron` dependencies | 仅 `electron`；toastui/d3/file-viewer/marked 在 **devDependencies**，构建时 sync 到 `renderer/vendor` 后从 `node_modules` 删除 |

### 为什么开发机正常、其它电脑失败？

旧构建用 `python -m venv`，生成的 `python\Scripts\python.exe` 依赖开发机上的  
`C:\Users\…\Python3xx\python.exe`。开发机有该路径故能跑；用户机没有 → 启动报「知识库初始化失败 / python exited with code 103」等。

自定义安装路径**不是根因**（安装目录任意均可）。**必须用本页新方法重新打安装包**，旧 Setup 无法只靠补丁修好内置 Python。

发版前在**干净电脑 / VM（无本机 Python）**上安装验证：

1. 安装到非默认路径（例如 `D:\Apps\Yizhi`）
2. 启动 → 应进主界面 / 试用提示
3. 确认安装目录存在 `python\python.exe`，且**没有** `python\pyvenv.cfg`

### 产出文件

| 路径 | 说明 |
|------|------|
| `dist\Yizhi-Setup-<版本>.exe` | **给用户的主安装包**（约 300MB+） |
| `dist\Yizhi-Staging-<版本>\` | 中间目录，可调试 staging |
| `docs\commercial\yizhi-web\latest.json` | 更新清单，须上传服务器 |
| `dist\Yizhi-Staging-<版本>\yizhi-web\` | 同上 + purchase/faq 副本 |

**首次全量构建约 30～60 分钟**（含 pip、npm、Inno 压缩）；属正常现象。

## 四、仅重新编译安装包（改 iss / 文案 / 图标后）

staging 已存在、只需重打 Inno 时：

```powershell
cd E:\app\Myknowledge

  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -JwtSecret "<LICENSE_JWT_SECRET>" `
  -SkipPortableBuild `
  -SkipVCRedistDownload
```

仍约 **20～40 分钟**（Inno 压缩体积大）。

## 五、常用参数

| 参数 | 说明 |
|------|------|
| `-LicenseServer` | 注入 `MYKNOWLEDGE_LICENSE_SERVER` |
| `-JwtSecret` | 注入 `MYKNOWLEDGE_LICENSE_JWT_SECRET` |
| `-EnvFile` | 大模型配置源，默认项目根 `.env` |
| `-SkipPortableBuild` | 跳过 staging，只编译 iss |
| `-SkipTools` | 跳过 ffmpeg/bun（加快构建，功能可能不全） |
| （环境变量）`MYKNOWLEDGE_ALLOW_GITHUB_TOOLS=1` | `setup_optional_tools` 默认**只复制本机** ffmpeg/bun（如 `C:\ffmpeg\bin`、npm 全局 bun），**不访问 GitHub**；仅在确需联网时再开此开关 |
| （环境变量）`MYKNOWLEDGE_FFMPEG_PATH` / `MYKNOWLEDGE_BUN_PATH` | 指定本机可执行文件，构建时会复制进 `third_party/` |
| `-SkipDocubrowser` | 跳过 DocuBrowser |
| `-SkipVCRedistDownload` | 不下载 VC++（staging 里已有 redist 时用） |
| `-InnoSetupPath` | 手动指定 `ISCC.exe` 路径 |
| `-InstallInnoSetup` | 未找到 ISCC 时尝试自动安装 |

## 九、常见问题

### 找不到 ISCC

```powershell
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" /?
```

或：`.\scripts\build-installer.ps1 ... -InstallInnoSetup`

### 安装后启动报「找不到文件」、路径乱码

须用 **`YizhiStart.vbs`**（桌面/开始菜单快捷方式默认指向此文件）。`YizhiStart.bat` 仅薄封装转调 VBS，勿直接用会挂控制台的旧 bat 起 Electron。

### 安装时提示「无法自动关闭应用程序」/ 无法继续安装

Inno Setup 检测到 **`C:\Program Files\Yizhi`** 下文件仍被占用（常见为上次安装的 **Python / Electron** 未退出）。Setup 日志示例：

```text
RestartManager found an application using one of our files: Python
Some applications could not be shut down.
User chose Abort.
```

**处理：**

1. 任务管理器结束 **易知 / electron.exe / 相关 python.exe**
2. 或运行项目根目录 `stop-yizhi.bat`（若 staging 中有）
3. 重新运行安装包

当前 `YizhiSetup.iss` 已设 **`CloseApplications=force`**，覆盖安装时会强制结束占用进程；若仍失败，请先手动退出易知再装。

### 安装进度页出现大块灰条、进度条被遮挡

原因为安装页轮播文案控件 **Parent 与 ProgressGauge 不一致**，坐标错位后遮住进度条。已改为与 `ProgressGauge` 同 Parent，并放在进度条**下方**（高度约 40px）。

### 安装后 YizhiStart.vbs 报「无效字符 / 800A0408」

`wscript.exe` 只能编译 **纯 ASCII** 的 `.vbs`；脚本中含中文或 UTF-8 中文注释会触发编译错误。当前 `YizhiStart.vbs` 已改为英文提示；构建时会校验并强制 ASCII 写入。

**已安装旧包临时绕过：** 以管理员 PowerShell 执行 `scripts\installer\patch-installed.ps1`（会更新 VBS、启动页 splash、electron\main.js），或手动复制上述文件。

### 安装后启动出现黑色控制台窗口

常见原因：快捷方式仍指向 **`YizhiStart.bat`**，且 bat 内用 `start`/`cmd` 直接拉起 Electron，控制台会继承 `[yizhi-boot]` 日志。

当前安装版要求：

1. **快捷方式 / 开机自启 / 安装后启动** → `{app}\YizhiStart.vbs`（勿指 .bat）
2. **`YizhiStart.vbs`** 以隐藏窗口启动 `electron.exe`，并设置 `ELECTRON_NO_ATTACH_CONSOLE=1`
3. **`YizhiStart.bat`** 仅 `start "" wscript.exe …YizhiStart.vbs` 后立刻退出（备用）
4. 后端日志写入 `%LOCALAPPDATA%\Yizhi\backend.log`，不弹窗

**已安装旧包（管理员 PowerShell）：**

```powershell
.\scripts\installer\patch-installed.ps1
```

会更新 VBS/bat，并尽量把桌面与开始菜单「易知」快捷方式改指 `.vbs`。完成后请完全退出易知再开一次。

### 安装后报 Access denied / 无法创建 `.license`

安装目录 `C:\Program Files\Yizhi` 对普通用户只读。安装版须把**用户数据**写到 `%LOCALAPPDATA%\Yizhi`（笔记、`.env`、`.license`、RAG 索引等）。

当前 `electron/main.js` 在 `YIZHI_INSTALLED=1` 时会自动切换；须重新打包安装或执行 `patch-installed.ps1`。

### Inno 编译很慢

正常。压缩 300MB+ 内置运行环境，请耐心等待，勿重复启动第二次编译。

**用户侧安装慢**主要来自解压 + 写入 `python\Lib\site-packages` 与 `electron\node_modules` 中大量小文件（杀毒软件扫描会进一步拖慢）。当前构建已做：

| 优化 | 效果 |
|------|------|
| `Compression=lzma2/max` + `SolidCompression=no` | 解压比 ultra64/solid 更快，安装包略大 |
| staging 精简 | `scripts/prune_install_staging.ps1`：删 `__pycache__`/`*.pyc`/`*.map`、tests、docs、dev 脚本等 |
| 安装页轮播文案 | 进度条下方每 10% 切换一条产品亮点金句 |

若仍嫌慢，可提示用户安装时暂时关闭实时杀毒扫描（安装完成后再开）。

### 安装包 .exe 在资源管理器里仍显示 Inno 默认图标

1. **重新编译**：`SetupIconFile` 使用 `scripts/installer/Yizhi.ico`（与 `.iss` 同目录）；勿用 `/DMyAppIcon=E:\app\...`（路径中 `\a` 会被 ISPP 转义导致图标未嵌入）。
2. **刷新图标缓存**（嵌入正确但 Explorer 仍显示旧图时）：

```powershell
ie4uinit.exe -show
# 或重启资源管理器
Stop-Process -Name explorer -Force; Start-Process explorer
```

也可把 `Yizhi-Setup-x.x.x.exe` 改个文件名再改回，强制 Shell 重读图标。

### 清理 staging 报「目录被占用 / DocuBrowser」

常见原因：资源管理器打开了 `dist\Yizhi-Staging-*`、上次构建的易知/Electron 未退出、或开发中的 DocuBrowser 进程仍运行。

1. 关闭易知窗口及任务管理器中的 `electron.exe` / 相关 `python.exe`
2. 关闭资源管理器中打开的 `dist` 目录
3. 重新执行 `build-installer.ps1`

构建脚本会先重试删除；仍失败时会将旧 staging 改名为 `Yizhi-Staging-<版本>.old-<时间戳>` 并继续，可稍后手动删除 `.old-*` 目录释放空间。

### 仅要 zip 便携版（不要 Inno）

```powershell
.\scripts\build-portable.ps1 `
  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -JwtSecret "<LICENSE_JWT_SECRET>"
```

产出目录：`dist\Yizhi-Portable-<版本>\`，用户运行 `启动易知.bat`。
