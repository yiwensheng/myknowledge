# 易知 · 常见问题 FAQ

## 安装与启动

**Q：提示找不到 Python / Node？**  
A：请使用官方安装包（内置运行环境）。若仍报错，重新下载最新版或联系客服。

**Q：首次启动很慢？**  
A：首次需初始化知识库与索引，属正常现象；后续启动会快很多。

## 大模型与能力检测

**Q：提问没反应或报错？**  
A：打开「设置 → 大模型」，确认 API 地址、Key、模型名称正确；「设置 → 能力检测」中 **大模型 API** 须为绿色。

**Q：能力检测有红项？**  
A：打开「设置 → 能力检测」→ **一键修复可选工具**（或运行 `python scripts/setup_optional_tools.py`）。Rerank / Embedding 需你的 API 服务商支持对应模型。

**Q：订阅包含 API 费用吗？**  
A：**不包含**。软件订阅只含易知使用权；LLM、TTS 等按各平台自行计费。

## 订阅与支付

**Q：支付成功但未解锁？**  
A：等待 1～2 分钟自动刷新；仍不行请重启易知。若订单已扣款，联系客服并提供支付截图与设备 ID（关于页可见）。

**Q：如何查看到期日？**  
A：「关于」页显示订阅状态与到期时间。

**Q：离线能用吗？**  
A：可以。上次联网校验成功后 **7 天内** 可离线使用；超期需联网 heartbeat。

## 数据与隐私

**Q：笔记存在哪里？**  
A：全部在本地电脑（wiki 目录），不上传知识库内容。详见 [隐私说明.md](隐私说明.md)。

**Q：换电脑后资料还在吗？**  
A：知识库在旧机本地，需自行复制 wiki 文件夹到新电脑；订阅需在新机重新激活（可先自助解绑旧机）。

## 更新

**Q：如何检查新版本？**  
A：「关于」→ **检查更新**。有新版本时按提示下载安装包覆盖安装。
