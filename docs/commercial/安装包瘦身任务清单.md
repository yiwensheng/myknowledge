# 易知 · 安装包瘦身任务清单（方案 A）

> **前提**：见 [换栈决策基线](./换栈决策基线.md)。  
> **基线体积**：`Yizhi-Setup-2.3.0.exe` ≈ 462 MB；staging ≈ 1.5 GB。  
> **Sprint 1 状态**：**A1 / A5 / A6 已落地代码**（须重打安装包后量体积）；A2–A4 未做。

## 目标

- 安装包压到约 **200～300 MB**（压缩后），或至少磁盘安装体积明显下降。
- 默认启动路径：**仅** `runtime\yizhi-backend.exe`，不再依赖重复的完整 `python\`。
- 重型可选能力可缺省，首次启用再下载。

## A1 — 安装版只留 PyInstaller `runtime\`

**现状**：[`build-portable.ps1`](../../scripts/build-portable.ps1) 在 `-ForInstaller` 下既编 `runtime\yizhi-backend.exe`，又保留可搬迁 `python\`；[`build-installer.ps1`](../../scripts/build-installer.ps1) 仍校验/建议保留 `python\python.exe`。

**要做**

1. 增加构建开关，例如 `-NoBundledPythonFallback`（安装包默认开；便携排障包可关）。
2. [`prune_install_staging.ps1`](../../scripts/prune_install_staging.ps1)：安装 staging 删除 `python\`（或仅保留极小 bootstrap，若仍需要）。
3. [`YizhiSetup.iss`](../../scripts/installer/YizhiSetup.iss) / [`YizhiStart.vbs`](../../scripts/installer/YizhiStart.vbs)：自检改为「必须有 `runtime\yizhi-backend.exe`」，不再要求 `python\python.exe`。
4. [`electron/main.js`](../../electron/main.js) `backendLaunchSpec()`：安装版（`YIZHI_INSTALLED=1`）**禁止**静默回退到缺失的 python；失败时明确 ErrorBox + 指向日志。
5. 文档：更新 [`后端二进制化.md`](./后端二进制化.md)、[`构建安装包.md`](./构建安装包.md)——说明开发机仍用系统 Python；客户机仅 frozen。

**验收**

- [x] 构建链：`-ForInstaller` 默认 `prune -RemoveBundledPython`；Inno/`YizhiStart.vbs` 只认 `runtime\yizhi-backend.exe`
- [x] `main.js` 安装版禁止回退系统 Python；无 python 时跳过 cli init（后端 scaffold）
- [ ] 新安装目录无完整 `python\`（须重打 Setup 后人工确认）
- [ ] 冷启 spawn 行为 `yizhi-backend.exe`（重打后确认）
- [ ] 故意删 exe 时有清晰中文错误（重打后确认）
- [ ] T1–T8 核心路径通过（重打后确认）

**回退**：`.\scripts\build-installer.ps1 ... -KeepBundledPythonFallback` 保留 `python\`。

## A2 — ffmpeg / bun / yt-dlp 按需下载

**现状**：[`setup_optional_tools.py`](../../scripts/setup_optional_tools.py) 在打包装入 `third_party\`（ffmpeg ≈157 MB，bun ≈94 MB，yt-dlp ≈17 MB）。

**要做**

1. 安装包默认**不**打入 ffmpeg/bun（yt-dlp 可同策略或保留小体积组件）。
2. 能力探测：[`lib/runtime_tools.py`](../../lib/runtime_tools.py) / capabilities API 返回 `available: false` + `install_hint`。
3. UI：设置或首次使用播客/网页抓取/B 站字幕时提示「下载可选组件」（写入 `%LOCALAPPDATA%\Yizhi\tools\` 或 `{app}\third_party\`）。
4. 下载源：现有 GitHub/镜像逻辑复用；校验 hash；失败可重试。
5. 构建：`build-portable.ps1 -SkipOptionalTools` 成为安装包默认。

**验收**

- [ ] 默认安装包体积显著下降；无 `third_party\ffmpeg` 或仅为占位说明文件。
- [ ] 未下载时相关功能提示明确，不 500 崩溃。
- [ ] 有网下载后播客/抓取/B 站路径可用。

**风险缓解**：企业无网环境在发版说明中提供「完整工具包」可选下载页。

**现状**：GPL sidecar，[`docs/commercial/GPL说明.md`](./GPL说明.md)；端口 18766。

**要做**

1. 安装 staging 默认不 clone DocuBrowser；设置中「启用文档检索增强」再引导安装或外链说明。
2. 保持 GPL 边界：若随包分发须继续履行义务；外置可降低默认包体积与合规表面积。

**验收**

- [ ] 默认包无 DocuBrowser 树或仅文档链接。
- [ ] 关闭时提问/写作不受影响；开启路径有文档。

## A4 — 文件预览降级

**现状**：`@file-viewer/web-full` → `renderer/vendor/file-viewer` ≈130 MB，并污染 prune 后 `node_modules`。

**要做**

1. 默认预览策略：**PDF 用轻量 pdf.js（或系统默认）**；Office/其它 → `open-asset-system`（已有 IPC）。
2. 从 [`package.json`](../../electron/package.json) / sync 脚本移除 `web-full`；清理 vendor 与 prune 白名单。
3. UI 文案：「用系统应用打开」；可选「完整预览包」按需下载（若仍需要，可后置）。

**验收**

- [ ] staging 无 `renderer/vendor/file-viewer` 大目录。
- [ ] PDF 仍可预览或一键系统打开；其它格式系统打开成功。
- [ ] 安装包/electron 目录体积下降可测。
