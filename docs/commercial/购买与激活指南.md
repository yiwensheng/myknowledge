# 易知 · 购买与激活指南

> 面向最终用户。正式域名：`https://www.yzwhysxx.cn` · 购买页：`/yizhi/purchase.html`

## 1. 订阅包含什么

- 易知桌面软件使用权与版本更新
- 本地知识库、导入、问答、写文章、播客等功能
- **不含** 大模型 / TTS API 费用（须自备 Key，在「设置 → 大模型」中配置）

默认套餐（以购买页为准）：

| 套餐 | 参考价 |
|------|--------|
| 月付 | 19 元/月 |
| 年付 | 99 元/年 |

## 2. 下载与安装

1. 从官方渠道下载 `Yizhi-Setup-x.x.x.exe` 或便携包
2. 安装到任意目录（建议路径不含中文空格）
3. 首次启动若提示缺少 `.env`，将安装目录中的 `env.user.example` 复制为 `.env`
4. 在 `.env` 或「设置 → 大模型」中填写 **API 地址** 与 **API Key**

## 3. 激活订阅

1. 打开易知 → 弹出「激活易知」
2. 选择 **月付** 或 **年付** → 微信/支付宝扫码支付
3. 支付成功后页面自动解锁；也可输入 **激活码**（客服发放）
4. 「关于」页可查看：订阅有效 · 套餐 · 到期日

## 4. 续费

- 到期前打开易知 → 「关于」→ **续费 / 激活**
- 或访问购买页再次下单（到期日顺延）

## 5. 换机

- 每台电脑绑定一个设备 ID
- **自助换机**：关于 → 自助换机（默认每年 1 次）
- 超额或特殊情况联系客服人工解绑

## 6. 升级安装

覆盖安装新版本即可；**wiki 目录、`.env`、`.license` 会保留**。
