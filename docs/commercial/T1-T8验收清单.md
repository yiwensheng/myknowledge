## T1 详细步骤（mock）

1. 干净 VM 解压便携包，双击 `启动易知.bat`  
2. 设置 LLM Key（或跳过仅测授权门禁）  
3. 弹出激活页 → 选 **月付** → 记下 order_id（开发模式可见 mock 二维码）  
4. 运维：`python scripts/license_admin.py mark-paid <order_id>`  
5. 客户端 1～2 分钟内自动激活，或重启易知  
6. **验收**：提问/导入不再 402；关于页「订阅有效 · 月付」  

截图：激活页、关于页、`GET /api/license/status` 返回 `licensed: true`

## T3 激活码

```powershell
python scripts/license_admin.py create-code year
```

新机/清 `.license` 后输入激活码 → 关于页年付有效。

---

## T6 换机

1. 已激活机器：关于 → **自助换机**  
2. 新 VM 安装 → 重新订阅或激活码  
3. 旧机再使用应被拦截  

---

## T7 离线宽限

1. 激活后联网 heartbeat 成功  
2. 断网使用 7 天内应正常  
3. 超过 7 天（或改本地 `.license` 时间测试）应要求联网
