# 反馈闭环（落地说明）

## 行为

1. 用户在易知填写反馈（正文非空）→ 点「提交反馈」  
2. **先写入本地** `wiki/.feedback_queue/*.json`  
3. 有网则 `POST {MYKNOWLEDGE_LICENSE_SERVER}/feedback`  
4. 授权服 **先落盘** `feedback_inbox/`，再限时发信到 `ywsay@126.com`  
5. 发信成功或服务端已收件 → 删除本地队列文件  
6. 无网 / 超时 / 5xx → 本地保留，后台每 2 分钟重试  

## 授权服发信配置（必做，否则邮件发不出）

在服务器 `license-server/.env`：

```env
FEEDBACK_ENABLED=1
FEEDBACK_TO=ywsay@126.com
FEEDBACK_FROM=suddly@agent.qq.com
# 推荐 SMTP（QQ 邮箱授权码）：
FEEDBACK_SMTP_HOST=smtp.qq.com
FEEDBACK_SMTP_PORT=465
FEEDBACK_SMTP_SSL=1
FEEDBACK_SMTP_USER=suddly@agent.qq.com
FEEDBACK_SMTP_PASSWORD=<授权码>
```

或安装并登录 `agently-cli`（发件账号 `suddly@agent.qq.com`）作为降级。

## 运营台「反馈」页签

地址：`/license/admin/ui` → 页签 **反馈**。

- 有网提交的反馈写入 SQLite 表 `feedback`（并保留 `feedback_inbox/*.json` 备份）  
- 可按「已发信 / 未发信」筛选，点「查看」看正文  
- `GET /admin/feedback?admin_key=…`  

部署时另需覆盖：`app/db.py`、`app/static/admin/index.html`

将开发机以下文件同步到服务器 `C:\yizhi\license-server\`（路径以实际为准）后重启授权服进程：

- `app/main.py`
- `app/db.py`
- `app/feedback_mail.py`
- `app/feedback_store.py`（新）
- `app/static/admin/index.html`
- `.env` 中 FEEDBACK_* 段

**已知根因**：agently-cli 要求 `--body-file` 为**相对路径**；旧代码传绝对路径会失败。生产若曾卡住/502，部署本修复后应恢复。

验收：

```text
GET https://www.yzwhysxx.cn/license/health
→ feedback.smtp 或 feedback.agently 为 true；unmailed 为数字
```

提交一条反馈后，`ywsay@126.com` 应收到；断网提交应提示已排队本地。
