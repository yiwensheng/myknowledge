# 易知 · 后端二进制化（PyInstaller）

> 计划正文：[`docs/superpowers/plans/2026-07-15-yizhi-backend-binary.md`](../superpowers/plans/2026-07-15-yizhi-backend-binary.md)

## 决策

- **默认发版**：PyInstaller **onedir** → `{app}\runtime\yizhi-backend.exe`（`console=False`）
- **安装包 A1**：编好 `runtime\` 后**删除**重复的完整 `python\`（构建期仍短暂安装 python 以跑工具脚本）
- **诊断便携包**：`build-installer.ps1 ... -KeepBundledPythonFallback` 或 `build-portable.ps1 -ForInstaller -KeepBundledPythonFallback` 保留 `python\`
- **无二进制回退**：`build-installer.ps1 ... -SkipBackendBinary`（必须保留 `python\`）
- **Nuitka**：可选 Phase B，脚本 `scripts/packaging/nuitka-backend.ps1`，产出同一目录契约

## 启动链

1. `YizhiStart.vbs`：**必须**存在 `runtime\yizhi-backend.exe`；静默启动 Electron（不再回退 python）
2. `electron/main.js`：安装版（`YIZHI_INSTALLED=1`）仅 spawn frozen；缺失则中文 ErrorBox + 日志尾部
3. 开发树 / `YIZHI_DEV=1`：仍用系统 Python `-m backend`

## 本机构建

```powershell
cd E:\app\Myknowledge
.\scripts\build-backend-exe.ps1 -Clean
# 产出 dist\backend-runtime\yizhi-backend.exe
```

构建脚本会把 `PYTHONPATH` 临时设为仓库根，避免本机 LazyLLM/torch 等污染进包。

冒烟（自动）：启动 exe，请求 `http://127.0.0.1:18775/api/health` 应返回 200。失败时可看 `%LOCALAPPDATA%\Yizhi\frozen-boot.log`。

安装包（默认会编二进制）：

```powershell
.\scripts\build-installer.ps1 -LicenseServer "..." -JwtSecret "..."
```

## 验收要点

- 安装版 `electron-boot.log` / `backend.log` 中 `spawn` 行含 `yizhi-backend.exe`
- 桌面快捷方式无控制台黑窗
- 开发树（`YIZHI_DEV=1`）仍用系统 Python，不受影响
