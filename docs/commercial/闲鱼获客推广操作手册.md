## 七、按周操作流程

### 第 0 周：准备

通测官网与安装；写好标题/正文/主图；建转化表。

### 第 1 周：上架闲鱼

发 1～2 个 0 元宝贝（不同标题 A/B）；咨询必回下载主回复；引导「装好了」→ 5 分钟清单。

### 第 2～4 周：扩平台（同一套物料）

| 平台 | 怎么放 |
|------|--------|
| 小红书 | 场景笔记；置顶官网 |
| 抖音/视频号 | 15～30s 导入→提问 |
| 即刻 / V2EX | 软性分享，遵守版规 |
| 微信社群 | 答疑，勿群发硬广 |

原则：**外链最终进官网**。

### 转化节奏

- 软件内：试用将尽时看激活页  
- 闲鱼：D25 轻提醒月付  
- 可选：闲鱼专属「远程装机指导」服务，**不要**私送激活天数绕开系统
