## 第一步：构建用户安装包

> **完整步骤、参数说明与常见问题**见 [构建安装包.md](构建安装包.md)。  
> **每次测试成功的改动**须写入 [更新记录.md](../更新记录.md)（见 `.cursor/rules/yizhi-update-log.mdc`）。

在**开发机**（`E:\app\Myknowledge`）：

```powershell
cd E:\app\Myknowledge

# 首次需安装 Inno Setup 6（编译 .exe 安装包用，只需装一次）
# 若 winget 不可用：浏览器下载 innosetup-6.7.3.exe 后执行：
#   .\scripts\install-innosetup.ps1 -InstallerPath "下载路径\innosetup-6.7.3.exe"

.\scripts\run_commercial_preflight.ps1 `
  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -AdminKey "<LICENSE_ADMIN_KEY>" `
  -JwtSecret "<LICENSE_JWT_SECRET>"

.\scripts\build-installer.ps1 `
  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -JwtSecret "<LICENSE_JWT_SECRET>"
```

产出：`dist\Yizhi-Setup-2.0.0.exe`；同时生成 `docs\commercial\yizhi-web\latest.json`，须与安装包一并上传到服务器 `yizhi/`。

安装向导可选：**桌面快捷方式**、**开机自动启动**（写入当前用户 `HKCU\Run\Yizhi`）。

仅要 zip 便携版时：

```powershell
.\scripts\build-portable.ps1 `
  -LicenseServer "https://www.yzwhysxx.cn/license" `
  -JwtSecret "<LICENSE_JWT_SECRET>"
```

构建脚本会：**排除**开发机 wiki/上传/对话库，**初始化空知识库与空 SQLite**，并从开发机 `.env` **注入大模型配置**（设置页不显示）。

**勿**把 `license-server\.env`、虎皮椒密钥、Admin Key 打进包。
