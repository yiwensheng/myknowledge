3.0.0 2026-08-13

下载：Yizhi-Setup-3.0.0.zip

  • 服务闭环（本版重点）：顶栏「本周服务进度」引导测通大模型 → 入库/笔记 → 有出处提问 → 可选蒸馏；收起后可用顶栏「服务进度」再展开。设置「大模型」支持一键测试连接。
  • 场景模板：写文章旁可开模板——教师课堂六步（备课→上课→练习→作业→检测→反馈）、考研/教研、自媒体、职场、一人公司 OPC；草案预览确认后写入笔记，不编造未提供事实。
  • 到期资产：试用将尽或续费时展示本地笔记、提问、蒸馏等资产摘要，便于理解「为何续费」。
  • 知识库初始化：设置新增「初始化」选项卡，强提醒后可清零用户资料；外联只取消登记，不删外部真实目录与文件。
  • 继承：2.5.x 自我蒸馏、PDF 分栏/整表、有据问答与本地优先等能力。

2.5.0 2026-08-09

下载：Yizhi-Setup-2.5.0.zip

  • 自我蒸馏（本版重点）：启动后在知识库自动建立 distill/ 四层—— Memory（原始案例）、Skills（可复用范式）、Principle（取舍原则）、Meta（蒸馏规则）。 做完一件事，在「导入资料 → 工作流」运行蒸馏本次产出：把正文/摘要压成 1 条 Skill + 可选 Principle，并归档 Memory。 之后提问与写文章会自动检索 Skills/Principle，让 AI 按你的做事方式表达与取舍（仍只许用库内事实）。新手指引已补充说明（v4）。
  • 相对 2.4.2：2.4.2 已含 PDF 整表 Markdown 入库与扫描表 ONNX/OCR；2.5.0 在其上新增完整「自我蒸馏」闭环，不内置 Crawl4AI。
  • 继承：2.4.1 OCR 进检索、订阅角标仅付费显示，以及 2.4.0 安装启动/ffmpeg/播客等能力。

2.4.2 2026-08-07

下载：Yizhi-Setup-2.4.2.zip

  • PDF 整表进检索：数字 PDF 用 pdfplumber 提取完整表格为 Markdown（第N页-表格K），避免表格被拆成碎行。可用 MYKNOWLEDGE_PDF_TABLES=0 关闭。
  • 扫描表增强：弱文本页可用随包 ONNX 表格检测（Microsoft TATR）+ Tesseract；无模型时自动降级为 OCR 启发式。开关 MYKNOWLEDGE_PDF_LAYOUT。
  • 未改：不内置 Crawl4AI；URL 抓取仍用现有 baoyu 路径（包体与换机可控）。
  • 继承 2.4.1：PDF 内嵌图/扫描页 OCR、订阅角标仅付费显示等。

2.4.0 2026-08-04

下载：Yizhi-Setup-2.4.0.exe

  • 安装启动修复：修复安装版引擎因 DocuBrowser 旁路误启动而超时失败的问题；请使用本页最新 Setup。
  • 内置 ffmpeg：安装包携带完整 ffmpeg（含 DLL），播客完整音频合并与音视频处理开箱可用。
  • 播客完整合成：对话脚本全文按主持人/嘉宾分段 TTS 并合并成完整文件；修复台词含「脚注」等词时音频被截断约 1 分钟的问题；合成后可在写文章页直接播放与下载。
  • 写文章布局：整页一条滚动条；草稿编辑器随正文流式增高，避免叠字或挤掉上方控件。
  • 新手指引 v3：对齐 2.4 能力（导入含 B 站字幕/外联 → 提问与续航知签 → 推演 → 写文章与播客 → 记忆与进化/矛盾检测 → 反馈等）；升级用户会再引导一次，亦可在「关于」重播。
  • 意见反馈：顶栏反馈入口支持富文本；修复弹窗过窄、正文编辑区几乎看不见的问题（加大弹窗与编辑区高度）。
  • 订阅状态展示：左上角仅在已付费订阅时显示方案与有效期；试用期间不再显示「试用剩余 N 天」。
  • 记忆与进化：续航条与「记忆与进化」面板跟踪规则、会话、审计；优质问答可归档，库随使用变厚。
  • 矛盾检测：对照核心假设扫描互相矛盾的表述并生成对照稿（不自动合并笔记）。
  • 检索增强：父-子分块、冲突提示；可选 HyDE；提问更贴原文、多源冲突更清晰。
  • 今日知签 / 库运势：趣味宜忌与基于近 7 日真实统计的库况解读；八日签册；写文章可选「今日可归档」清单（默认关）。
  • 目标任务书（leader）：工作流一键生成可执行任务书；内置去 AI 味写作约束（可关）。
  • 系统要求：仅支持 64 位 Windows 10（1809+）/ Windows 11；不支持 32 位系统。
  • 安装与体积：安装版优先仅用冻结后端、精简 Electron 依赖；启动闪屏分阶段提示并汇总失败日志。
