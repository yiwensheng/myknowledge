# 易知 · 隐私说明

> 发布前请补充运营主体名称、联系方式与生效日期。

## 1. 我们收集什么

### 本地（不上传）

- 您导入的文档、笔记、问答记录、向量索引等 **全部存储在您的电脑**
- 大模型 API Key 保存在本机 `.env`，**不会** 发送给易知运营方

### 授权服务器（仅订阅相关）

为完成订阅、绑机、续费，客户端会向授权服务器发送：

- 设备 ID（硬件指纹哈希，非姓名/手机号）
- 订单号、套餐、到期时间等订阅状态
- 心跳时间（用于离线宽限校验）

**不会** 上传知识库正文、提问内容、API Key。

### 支付

支付由 **虎皮椒** 等第三方支付平台处理；我们收到支付结果通知，不存储您的完整支付账号。

## 2. 我们如何使用

- 验证订阅是否有效、是否绑定当前设备
- 处理续费、换机解绑
- 客服补单与对账（订单号级别）

## 3. 存储与安全

- 授权记录存于云主机 SQLite（`license.db`），HTTPS 传输
- JWT 密钥用于客户端验签，请从官方渠道获取安装包

## 4. 您的权利

- 卸载软件可删除本地全部数据
- 联系客服查询/解绑设备、咨询订单
