# 易知 · 授权统计与报表

> 运维在**授权服务器**上查看订阅分类、收入、活跃设备。数据来自 `license.db`，不上传用户笔记。

---

## 一、部署本次更新（必做）

### 1. 开发机验证通过后，同步到生产服务器

将以下文件覆盖到服务器 `C:\yizhi\license-server\`（路径以你实际部署为准）：

| 文件 | 说明 |
|------|------|
| `license-server/app/db.py` | heartbeat 写入 `last_seen_at`；启动时自动补列 |
| `license-server/app/stats.py` | 统计逻辑（新文件） |
| `license-server/app/main.py` | 新增 `GET /admin/stats` |
| `scripts/license_admin.py` | 新增 `stats`、增强 `export-csv` |

### 2. 重启授权服务

```powershell
# 若用 NSSM / 计划任务 / 手动窗口，先停再启
cd C:\yizhi\license-server
python -m app.main
```

**首次启动**会自动执行：

```sql
ALTER TABLE licenses ADD COLUMN last_seen_at TEXT NOT NULL DEFAULT '';
```

无需手工跑迁移脚本；**不删、不改**现有订单与授权数据。

### 3. 验证

```powershell
cd E:\app\Myknowledge   # 或服务器上的 Myknowledge 副本目录

# 健康检查
python scripts/license_admin.py health

# 统计报表（读本地 license.db）
python scripts/license_admin.py stats --db C:\yizhi\license-server\license.db

# 按日 / 周 / 季 / 年
python scripts/license_admin.py stats --period day --db C:\yizhi\license-server\license.db
python scripts/license_admin.py stats --period week --db C:\yizhi\license-server\license.db
python scripts/license_admin.py stats --period quarter --db C:\yizhi\license-server\license.db
python scripts/license_admin.py stats --period year --db C:\yizhi\license-server\license.db

# JSON 输出（便于脚本处理）
python scripts/license_admin.py stats --format json --db C:\yizhi\license-server\license.db

# HTTP API（admin_key 与服务器 LICENSE_ADMIN_KEY 一致）
curl "https://www.yzwhysxx.cn/license/admin/stats?admin_key=<KEY>&period=month"
```

## 二、日常用法

### 订阅与收入一览

```powershell
$env:LICENSE_DB = "C:\yizhi\license-server\license.db"
python scripts/license_admin.py stats
```

输出包含：

| 区块 | 含义 |
|------|------|
| **有效订阅** | 已绑设备且未过期，按 月付/年付/终身 分类 |
| **待支付订单** | 用户下单未扫码 |
| **累计收入** | `orders.status=paid` 汇总 |
| **按日/周/月/季/年收入** | `--period` 控制粒度 |
| **近月新增授权** | 按 `starts_at` |
| **激活码** | 未使用 / 已使用 |
| **活跃设备** | 7 天 / 30 天内有过 heartbeat 的 distinct 设备数 |

### 导出原始数据（对账 / Excel）

```powershell
# 合并 CSV（含 orders、licenses、activation_codes、events）
python scripts/license_admin.py export-csv --db C:\yizhi\license-server\license.db --out C:\yizhi\exports\all.csv

# 分表导出（推荐）
python scripts/license_admin.py export-csv --split C:\yizhi\exports\2026-07-13 --db C:\yizhi\license-server\license.db
```

产出：`orders.csv`、`licenses.csv`、`activation_codes.csv`、`events.csv`。

### 与虎皮椒对账

1. `export-csv --split` 导出 `orders.csv`
2. 筛选 `status=paid`，按 `paid_at`、`plan`、`amount` 透视
3. 与虎皮椒商户后台到账记录核对

## 三、活跃设备说明

| 指标 | 定义 |
|------|------|
| **有效订阅** | 有授权、已绑机、未过期（不等于「在用」） |
| **7 天 / 30 天活跃** | 该时间段内客户端成功 `POST /license/heartbeat` 的设备数 |
| **从未 heartbeat** | 已绑设备但 `last_seen_at` 为空（多为升级前老用户，打开软件后会写入） |

**注意：**

- 试用用户仍不在服务器统计范围内（仅本地）
- 离线 7 天内可不联网，期间不会更新 `last_seen_at`
- 活跃数 = **联网校验过的设备数**，不是 DAU/打开次数

## 四、建议运维节奏

| 频率 | 操作 |
|------|------|
| 每日 | 可选：`stats --period day` 看昨日收入 |
| 每周 | `export-csv --split` + `stats` 存档 |
| 每月 | `stats --period month` + 虎皮椒对账 |
| 随时 | `backup_license_db.ps1` 备份 |

## 六、API 参考

```
GET /admin/stats?admin_key=<KEY>&period=month&active_days=30
```

`period`: `day` | `week` | `month` | `quarter` | `year`

返回 JSON，字段与 `license_admin.py stats --format json` 相同。

更多管理命令见 [易知授权运营.md](../易知授权运营.md)、[license-server/README.md](../../license-server/README.md)。
