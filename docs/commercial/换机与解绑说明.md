# 易知 · 换机与解绑说明

## 一机一码

每台电脑对应一个 **设备 ID**（关于页或激活流程中可见）。一个有效订阅在同一时刻只能绑定 **一台** 设备。

## 自助换机（推荐）

1. 在 **旧电脑** 打开易知 → 「关于」
2. 点击 **自助换机（每年 1 次）** → 确认
3. 在新电脑安装易知 → 重新 **订阅/激活** 或输入激活码

默认政策：**每年 1 次** 自助解绑。超额请联系客服。

## 客服换机

提供：购买凭证、原设备 ID、换机原因。核实后我们可在后台解绑，您在新机重新激活。

## 知识库迁移

解绑/换机 **不会** 自动迁移笔记。请将旧机 wiki 目录（或整个易知数据文件夹）复制到新电脑相同位置，或在新机重新导入资料。

## 常见问题

**Q：解绑后旧机还能用吗？**  
A：不能。解绑后旧机需重新订阅才能使用全部功能。

**Q：重装系统算换机吗？**  
A：若设备 ID 变化，需重新激活；可先尝试在原系统解绑再重装。
