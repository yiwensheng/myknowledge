如何购买

  1. 下载并安装易知（Windows 便携包或安装包）
  2. 首次启动配置大模型 API Key（设置 → 大模型）
  3. 安装后自动开始 30 天试用；试用结束后在「激活易知」页订阅
  4. 在「激活易知」页选择月付、年付或终身版，微信扫码支付
  5. 支付成功后自动解锁；也可使用客服发放的激活码

订阅包含

  • 易知桌面软件全部功能（导入、问答、写作、播客等）
  • 版本更新（关于 → 检查更新）
  • 一机一码；换机每年 1 次自助解绑
