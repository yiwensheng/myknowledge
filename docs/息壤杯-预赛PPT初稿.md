## 第 2 页 · 痛点：一人公司的三个断裂

| 断裂 | 现象 | 后果 |
|------|------|------|
| **存** | PDF、网页、聊天记录、音视频散落各处 | 找材料比做事还久 |
| **问** | 通用 AI 爱补全、爱编造 | 不敢据此选型、报价、拍板 |
| **产** | 写过的方案、朋友圈、答疑聊完即丢 | 每次从零，无法自我进化 |

一句话：不是缺大模型，是缺**只基于自己资料、越用越强**的经营系统。

---

## 第 3 页 · 解决方案

```text
进库（多格式）
   → 有据问答（无命中拒答）
   → 知识图谱 / 选型对比 / 未来推演（辅助决策）
   → 多体例写作 + 播客
   → 定稿回写
   → Skills + Loop 自我进化
```

**定位**：本地优先的一人公司第二大脑。

## 第 6 页 · 创新点

1. **事实约束**：无检索命中则拒答，降低经营决策幻觉风险  
2. **决策辅助**：图谱梳理 + 选型对比 + 情景/未来推演  
3. **闭环进化**：产出回写 + Loop/Skills，越用越贴生意  
4. **内容复用**：文章一键播客，适合一人公司获客  
5. **本地优先 + 可订阅**：隐私与商业化兼顾
