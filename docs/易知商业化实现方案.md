# 易知商业化实现方案

> **文档版本**：2026-07-12  
> **适用路径**：单机订阅软件（本地知识库 + 云端授权/支付）  
> **关联文档**：[易知授权运营.md](易知授权运营.md)、[易知项目报告书.md](易知项目报告书.md)、[license-server/README.md](../license-server/README.md)

---

## 1. 目标与边界

### 1.1 商业化目标（第一期）

在 **不改变「本地优先、数据不上云」** 的前提下，实现：

1. 用户下载安装包 → 打开易知 → 订阅/激活 → 正常使用全部功能
2. 你在云主机运营授权服务：收款、发证、绑机、续费、换机
3. 具备 FAQ、激活说明、基础售后流程，可服务 **5～50 名** 付费种子用户

### 1.2 明确不做（本期）


| 不做              | 原因                             |
| --------------- | ------------------------------ |
| 多租户 SaaS（浏览器即用） | 与现有架构相反，需另立项                   |
| 企业 SSO / 组织权限   | 无现成模块，二期再议                     |
| 100% 防破解        | 纯客户端无法做到；方案面向 honest 用户 + 一机一码 |
| 代管用户 LLM Key    | 用户自备 API，降低你的算力成本与合规负担         |


### 1.3 现状快照（2026-07）


| 维度   | 完成度   | 说明                                       |
| ---- | ----- | ---------------------------------------- |
| 产品功能 | ★★★★☆ | 五期路线图已完成；能力检测 7 项可全绿                     |
| 授权代码 | ★★★★☆ | `license-server/` + 客户端激活页、中间件、heartbeat |
| 分发交付 | ★★☆☆☆ | 依赖 `launch-yizhi.bat` + 用户自装 Python/Node |
| 支付运营 | ★★☆☆☆ | 虎皮椒接口已有，生产环境未部署                          |
| 支持体系 | ★★☆☆☆ | 文档有，缺购买页/FAQ/工单流程                        |


**结论**：离「能卖订阅」主要差 **安装分发、授权上线、用户支持** 三块，而非核心 RAG/问答能力。

## 2. 总体架构

```
┌──────────────────── 用户电脑（本地） ────────────────────┐
│  易知安装包（Electron + Python 后端）                      │
│  · wiki / .rag / assets 全在本地                          │
│  · .license/state.json 存订阅状态                         │
│  · 启动时校验 JWT；7 天离线宽限（heartbeat）               │
└──────────────────────────┬──────────────────────────────┘
                           │ HTTPS（仅授权/支付，不传库内容）
                           ▼
┌──────────────────── 云主机 VPS ───────────────────────────┐
│  license-server :18888（Nginx 反代 443）                   │
│  · POST /license/create-order → 虎皮椒二维码               │
│  · POST /pay/xunhupay/notify ← 支付回调                    │
│  · POST /license/activate · GET /license/order/{id}        │
│  · POST /admin/* 管理：mark-paid / unbind / create-code    │
│  · license.db 订单与授权记录                               │
└───────────────────────────────────────────────────────────┘
```

**密钥分工**（详见 [易知授权运营.md](易知授权运营.md)）：

- **服务器** `.env`：`LICENSE_JWT_SECRET`、`LICENSE_ADMIN_KEY`、虎皮椒密钥 — **绝不打入用户包**
- **用户包** `.env`：`MYKNOWLEDGE_LICENSE_SERVER`、`MYKNOWLEDGE_LICENSE_JWT_SECRET`（验签用，与服务器相同属正常）、`MYKNOWLEDGE_LICENSE_REQUIRED=1`

### 阶段 1：授权服务生产部署（第 1～2 周）

**目标**：公网可用的 `https://license.你的域名`，能创建订单、收回调、发证。

#### 1.1 云主机与环境

```powershell
# 云主机：2C4G 即可；系统 Ubuntu 22.04+ 或 Windows Server
# 开放：443（Nginx）、22（SSH）；18888 仅内网或 localhost
```


| 步骤                      | 命令/配置                                          |
| ----------------------- | ---------------------------------------------- |
| 安装 Python 3.10+         | `apt install python3 python3-venv python3-pip` |
| 克隆/上传 `license-server/` | 勿与易知用户包混在同一目录对外暴露                              |
| 配置环境                    | `copy .env.example .env` 并编辑                   |


`.env` **必填项**：

```env
LICENSE_PORT=18888
LICENSE_JWT_SECRET=<64位以上随机串>
LICENSE_ADMIN_KEY=<管理用随机串>
LICENSE_PRICE_MONTH=29
LICENSE_PRICE_YEAR=299
LICENSE_UNBIND_PER_YEAR=1

# 生产关闭 mock
LICENSE_DEV_MOCK_PAY=0

XUNHUPAY_APPID=<虎皮椒 AppId>
XUNHUPAY_APPSECRET=<虎皮椒 AppSecret>
XUNHUPAY_NOTIFY_URL=https://license.你的域名/pay/xunhupay/notify
XUNHUPAY_RETURN_URL=https://你的官网/支付成功
```

#### 1.2 进程与反向代理

```bash
cd /opt/yizhi-license-server
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt

# systemd 示例（/etc/systemd/system/yizhi-license.service）
# ExecStart=/opt/yizhi-license-server/.venv/bin/python -m app.main
# 开机自启：systemctl enable --now yizhi-license
```

Nginx 片段：

```nginx
server {
    listen 443 ssl;
    server_name license.你的域名;
    location / {
        proxy_pass http://127.0.0.1:18888;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```

#### 1.3 联调验收


| 检查项      | 命令/操作                                                      | 期望                     |
| -------- | ---------------------------------------------------------- | ---------------------- |
| 健康检查     | `GET https://license.你的域名/health`                          | 200                    |
| 套餐列表     | `python scripts/license_admin.py plans`                    | 返回 month/year 价格       |
| 创建订单     | 客户端或 curl `POST /license/create-order`                     | 返回 `order_id`、`qr_url` |
| 支付回调     | 虎皮椒后台测试回调 / 真实小额支付                                         | 订单变 paid               |
| 手动标记（应急） | `python scripts/license_admin.py mark-paid <order_id>`     | 可激活                    |
| 激活码      | `python scripts/license_admin.py create-code year`         | 返回 code，客户端可激活         |
| 解绑       | `python scripts/license_admin.py unbind --license-id <id>` | 设备可重新激活                |


**阶段验收**：生产域名下完整走通「下单 → 支付 → activate → heartbeat」；`license.db` 有记录。

### 阶段 2：客户端分发包（第 2～4 周，可与阶段 1 并行）

**目标**：普通用户 **无需** 手动安装 Python、pip、npm，双击安装即可启动。

#### 2.1 当前缺口

`launch-yizhi.bat` 要求：

- 系统 PATH 中有 `python`、`node`
- 首次运行 `pip install`、`npm install`（耗时长、易失败）

#### 2.2 推荐方案（分两步）

**2.2.1 短期（1～2 周）：「半自动安装包」**

创建 `scripts/build-portable.ps1`（待实现），产出目录结构：

```
Yizhi-Portable/
├── python/          # embeddable Python 3.11+ 或 pyinstaller 打包的后端
├── app/             # Myknowledge 源码（不含 .env、不含 license-server）
├── electron/        # 已 npm install + sync-file-viewer 的完整 node_modules
├── 启动易知.exe     # 或 启动易知.bat 固定相对路径调用内置 python/node
└── README.txt       # 首次运行：复制 .env.user → .env，填写 LLM Key
```

实施步骤：


| 步骤  | 说明                                                                                                  |
| --- | --------------------------------------------------------------------------------------------------- |
| A   | 下载 [Python embeddable](https://www.python.org/downloads/windows/) 解压到 `python/`                     |
| B   | 预执行 `pip install -r requirements.txt` 到 embed 的 site-packages                                       |
| C   | 预执行 `cd electron && npm install && npm run sync-file-viewer`                                        |
| D   | 修改启动脚本：优先使用 `%INSTALL_DIR%\python\python.exe` 与 `%INSTALL_DIR%\electron\node_modules\.bin\electron` |
| E   | 运行 `scripts/setup_docubrowser.py`、`scripts/setup_optional_tools.py` 写入可选工具                          |
| F   | 用 7-Zip / Inno Setup 打成 `Yizhi-Setup-2.0.0.exe`                                                     |


**2.2.2 中期（3～4 周）：electron-builder 安装包**

在 `electron/package.json` 增加：

```json
"build": {
  "appId": "com.yizhi.myknowledge",
  "productName": "易知",
  "directories": { "output": "dist" },
  "extraResources": [
    { "from": "../", "to": "backend", "filter": ["**/*", "!electron/**", "!license-server/**", "!.git/**"] }
  ],
  "win": { "target": ["nsis"], "icon": "assets/icon.ico" }
}
```

主进程 `main.js` 启动时 spawn 内置 Python 跑 `python -m backend`（需开发任务：打包后路径解析）。

#### 2.3 用户包内 `.env` 模板

分发 `env.user.example`（安装时复制为 `.env`）：

```env
# === 用户必填 ===
MYKNOWLEDGE_LLM_API_BASE=https://你的LLM服务/v1
MYKNOWLEDGE_LLM_API_KEY=
MYKNOWLEDGE_LLM_MODEL=qwen3.6

# === 订阅（安装包预填，勿改 JWT）===
MYKNOWLEDGE_LICENSE_REQUIRED=1
MYKNOWLEDGE_LICENSE_SERVER=https://license.你的域名
MYKNOWLEDGE_LICENSE_JWT_SECRET=<与服务器相同，构建时注入>

MYKNOWLEDGE_PORT=18765
```

**禁止** 打入：`LICENSE_ADMIN_KEY`、虎皮椒密钥、你的个人 LLM Key。

#### 2.4 阶段验收


| 检查项                  | 期望                            |
| -------------------- | ----------------------------- |
| 干净 Windows 10/11 虚拟机 | 无全局 Python/Node 也能启动          |
| 首次启动                 | 自动 `init` wiki 目录；弹出激活页（未订阅时） |
| 升级                   | 文档说明「覆盖安装保留 wiki 与 .env」      |

### 阶段 4：支付与激活全链路验收（第 4 周）

**目标**：模拟真实用户从购买到使用的完整路径。

#### 4.1 测试用例矩阵


| #   | 场景     | 操作                     | 期望                 |
| --- | ------ | ---------------------- | ------------------ |
| T1  | 新用户月付  | 选月付 → 扫码 → 等待轮询        | 自动关闭激活页，可提问        |
| T2  | 新用户年付  | 同上                     | `plan: year`，到期日正确 |

| T6  | 换机     | 旧机 self-unbind → 新机激活  | 成功；超额解绑拒绝          |
| T7  | 离线 7 天 | 断网使用                   | 宽限内可用；超期需联网        |
| T8  | 已付未解锁  | mark-paid 补单           | 客服流程文档化            |


#### 4.2 客户端激活流程（用户视角）

3. 支付成功自动解锁；或输入激活码
4. 关于页显示：订阅有效 · 套餐 · 到期日

## 6. 风险与对策


| 风险                | 对策                          |
| ----------------- | --------------------------- |
| 用户不会装 Python/Node | 阶段 2 便携包/安装包，禁止依赖全局环境       |
| 支付回调失败            | 客服 `mark-paid`；虎皮椒 IP 白名单   |
| JWT 泄露            | 仅客户端验签密钥可分发；Admin Key 仅服务器  |
| GPL 合规            | 附源码链接；不静态链接闭源替代 DocuBrowser |
| LLM 成本用户抱怨        | 定价文案写清「软件订阅不含 API」          |
| 破解                | 一机一码 + heartbeat；不投入无限对抗    |
