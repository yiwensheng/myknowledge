# 2026年下学期工作重点方案

## 目标与范围

本方案旨在明确2026年下学期（即2025-2026学年第二学期）学校工作的核心方向与执行路径。基于陈庆翔校长在期末总结大会上的讲话及俞敏洪老师提出的办学要求，本学期的工作范围覆盖全校各学部，重点聚焦于**生源质量、教师队伍、干部活力、教学质量、学生培养**五大维度。

具体目标设定如下：
1.  **生源质量**：落实《生源质量提升三年发展规划》，实现“宁缺毋滥”的优生筛选机制，力争各学部发布名额即被选满，整体流失率控制在4%以内。
2.  **教师建设**：推进教师评价体系与荣誉体系落地，实现48名教师职位晋升与98名教师薪级晋级的后续激励，杜绝“死海效应”。
3.  **干部活力**：打破干部岗位“终身制”，推进梯队结构优化与年轻化，确保重点工作100%完成。
4.  **升学目标**：国际高中形成牛剑藤校录取稳定态势；普通高中力争实现清北零的突破，冲击C9名校；初中双语达成中考成绩大市第一。
5.  **学生培养**：深化课堂改革3.0版，构建分层教学体系，提升科创与艺术素养。

## 现状与依据

当前学校处于“追求卓越、挑战极限”的关键转型期，外部环境充满挑战，内部发展仍有痛点。

**外部环境挑战：**
*   **经济因素**：经济波动导致民众消费趋于理性，对高收费民办学校构成考验。
*   **人口因素**：出生率下降影响幼儿园及小学招生，生源分流趋势明显。
*   **竞争加剧**：公办学校投入加大，周边民办学校竞争升级，家长对“高收费与高品质”匹配度要求严苛。
*   **技术冲击**：人工智能快速迭代，对传统育人方式提出全新考验。

**内部深层痛点：**
1.  **生源质量不够好**：高收费先天劣势影响优生选择，距离“招生部取消”的理想状态仍有差距。
2.  **师资力量不够强**：领军型名师和具有影响力的学科带头人较少。
3.  **干部活力不够足**：管理团队存在年龄断层、经验固化、专业能力不足瓶颈。
4.  **升学缺乏“高峰”效应**：虽有个别顶尖名校突破，但未形成稳定态势，清北、C9录取较难。
5.  **办学成本上升**：对成本管控和增收创效提出更高要求。

**已有基础：**
*   **项目驱动**：已搭建全校重点项目管理体系，8个重点项目及40个子项目纳入智能化管理，进度、责任、风险可视。
*   **成绩突破**：幼儿园圣三一考级历年最优；小学双语在作文、数学、英语竞赛中斩获多项金奖；国际高中实现牛津首枚突破；普高C9科创班签约态势良好。

## 总体思路

本学期工作主线延续“目标引领，项目驱动”，以俞敏洪老师提出的五大要求为方向，坚持“追求卓越、挑战极限”的实干精神。

首先，**坚持“宁缺毋滥”的生源观**。通过“拓源多引流、严选提门槛、标杆塑优生、内控抓留存”四轮驱动，让各学部从“家长选学校”转变为“学校选学生”，优化生源结构。

其次，**强化“能力与业绩双导向”的激励逻辑**。通过落地教师评价体系，让有实力、有实绩的教师获得平台与回报，坚决优胜劣汰，激活组织细胞。

最后，**深化“课堂改革与升学突破”的质量观**。针对不同学段痛点，实施分层教学与思维深度训练，冲击更高升学目标，同时兼顾科创、艺术等综合素质培养，打造差异化竞争优势。

## 重点任务详述

### 任务一：持续提升生源质量
*   **目的**：解决高收费劣势，优化生源结构，实现“宁缺毋滥”的优生筛选。
*   **步骤**：
    1.  **拓源多引流**：加大品牌宣传，利用现有标杆班型（如普高C9科创班、国中五年制启航班）的口碑效应吸引生源。
    2.  **严选提门槛**：在招生环节提高录取总分要求（如初中双语提高50分），严格筛选。
    3.  **标杆塑优生**：打造幼儿园全英文班、小学双语科创融合班等标杆项目，形成示范效应。
    4.  **内控抓留存**：关注在校生体验，将学年整体流失率控制在4%以内（当前为3.85%）。
*   **资源**：品牌市场部、各学部招生团队、质量管理办公室。
*   **验收标准**：各学部招生目标完成率达标，新生质量显著提升，流失率低于4%。

### 任务二：持续加强教师队伍建设
*   **目的**：解决师资短板，建立“能力导向”与“业绩导向”双轨并行的激励机制。
*   **步骤**：
    1.  **体系落地**：依据规则对教师进行积分评价、职位定性与薪级定位。
    2.  **荣誉激励**：推进教师荣誉体系，让教师清楚“有实力、有实绩就有平台、有回报”。
    3.  **优胜劣汰**：坚决动真碰硬，杜绝“死海效应”，避免优秀人才被庸者挤出。
    4.  **梯队培养**：落实教师发展三年目标，涵盖13项量化指标。
*   **资源**：人力资源部、各学部。
*   **验收标准**：教师积分评价完成，职位晋升与薪级晋级落地，教师满意度提升。

### 任务三：持续激发干部队伍活力
*   **目的**：打破年龄断层与经验固化，提升管理效能。
*   **步骤**：
    1.  **三大工程**：聚焦梯队结构优化、专业能力提升、管理效能突破。
    2.  **年轻化与动态调整**：打破干部岗位“终身制”，实现能上能下。
    3.  **深入一线**：管理团队率先垂范，在项目攻坚中锤炼本领。
    4.  **流程再造**：通过制度优化确保重点工作100%完成。
*   **资源**：校长室、人力资源部。
*   **验收标准**：干部队伍年轻化指标达成，管理流程优化，重点工作完成率达100%。

### 任务四：持续冲击更高升学目标
*   **目的**：打造升学高峰效应，提升学校核心竞争力。
*   **步骤**：
    1.  **国际高中**：在牛津首枚突破基础上，形成牛剑藤校录取的稳定态势。
    2.  **普通高中**：全力冲击C9名校，力争实现清北零的突破。
    3.  **初中双语**：早日达成中考成绩大市第一的目标，并在学生综合素质上取得领先。
*   **资源**：各学部教务处、备考团队。
*   **验收标准**：国际高中牛剑藤校录取人数增长；普高清北/C9录取实现突破；初中双语中考成绩全市领先。

### 任务五：深化学生培养与课堂改革
*   **目的**：应对AI时代挑战，提升学生思维深度与综合素质。
*   **步骤**：
    1.  **初中双语**：实施“面向每一位孩子的教学改进”项目，构建“环节清-知识点清-整课清”三级清学体系，解决分层教学五大症结。
    2.  **普通高中**：推进“课堂改革3.0版”，针对思维深度不足、训练针对性弱、分层辅导粗放三大痛点精准施策。
    3.  **国际中学**：新引进美国国际课程项目，提升英文课堂表达自信。
    4.  **科创与艺术**：巩固匹克球、合唱、书画等优势，深化英特戏剧教育实践基地成果。
*   **资源**：各学部教务处、质量管理办公室。
*   **验收标准**：课堂改革方案落地，学生竞赛获奖数量与质量提升，学生综合素质评价优良。

## 保障措施与风险

**保障措施：**
1.  **组织保障**：成立重点项目管理领导小组，搭建分工合作的领导和管理机制，每个项目明确责任人、时间表、路线图。
2.  **技术保障**：利用质量管理办公室开发的“项目质量管理平台”，实现全校重点项目及子项目的智能化管理，解决进度看不见、责任分不清、风险发现晚的问题。
3.  **资源保障**：确保新开设班型（幼儿园全英文班、小学双语科创融合班、普高C9科创班、国际中学启航班）的师资到位、课程就绪、保障有力。

**潜在风险：**
1.  **外部环境风险**：经济波动与人口下降可能导致生源增长乏力，需通过提升品质来对冲。
2.  **内部执行风险**：干部年轻化与优胜劣汰可能带来短期阵痛，需做好沟通与过渡。
3.  **竞争加剧风险**：周边学校竞争升级，需持续保持“高收费与高品质”的匹配度，避免家长满意度下降。

## 预期成果

通过本学期各项重点任务的推进，预期达成以下成果：
1.  **生源结构优化**：各学部招生目标超额完成，新生质量显著提升，流失率控制在4%以内，实现“学校选学生”的良性循环。
2.  **教师活力迸发**：教师评价体系有效运行，涌现一批领军型名师与学科带头人，教师队伍整体素质提升。
3.  **管理效能提升**：干部队伍年轻化、专业化，管理流程更加高效，重点工作100%完成。
4.  **升学高峰显现**：国际高中牛剑藤校录取稳定，普高清北/C9实现突破，初中双语中考成绩全市第一，学校品牌影响力进一步提升。
5.  **学生全面发展**：学生在学科竞赛、科创、艺术、体育等领域取得更多国家级、省级荣誉，综合素质显著增强。
