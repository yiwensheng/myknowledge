# 易知：从“会说话的外挂硬盘”到“自我进化的活书”

## 节目简介

本期节目基于《易知》产品说明及笔记片段，探讨个人知识库从“资料囤积”向“自我进化”的演进路径。针对当下“第二大脑”工具链断裂、AI 回答缺乏出处、优质内容无法回写的痛点，易知通过本地优先架构、混合检索与记忆进化机制，构建了一条从资料入库到推演、写作、播客的多模态流水线。节目将对比易知与常见 DIY 方案及通用 AI 工具的差异，解析其“进得来、搜得到、答有据、推有度”的核心逻辑，并讨论其适用人群与使用门槛。

## 对话脚本

**主持人**：咱们今天聊聊“易知”，也就是 Myknowledge。很多人都在折腾“第二大脑”，但往往最后发现，存得下却搜不到，或者搜到了却不敢用。易知想解决的核心痛点是什么？

**嘉宾**：痛点不是“不会用 AI”，而是“用不起来”。你大概经历过这种循环：把 PDF、会议纪要丢进文件夹，过两周问 AI “上季度质量复盘结论是什么”，它给一段通顺漂亮的话，但查无出处。你不敢用。或者答案全对，但散落在十个对话窗口里，库还是空的。所谓第二大脑，若只会聊天、不会长厚，那只是会说话的外挂硬盘。

**主持人**：也就是说，现在的工具链断了。易知是怎么把这条链接上的？

**嘉宾**：它把核心价值压成了一条链：资料进库 → 自动索引 → 有依据问答 → 优质内容回写 → 越用越聪明。具体手段并不神秘，但绑在一起才有意义。比如统一入库，PDF、PPT、Excel、Word、Markdown、图片、音视频、网页 URL 都能进。外联目录还能只读挂进检索，不必把整盘文件复制进库。

**主持人**：这个“只读挂进”很实用，不用搬移文件。那在检索上，它跟普通的搜索有什么区别？

**嘉宾**：它走的是混合检索的路子：关键词抓专有名词，Embedding 向量抓换种说法的同款意思，FTS5 全文索引与 RRF 融合排序齐头并进。回答只引库内片段，脚下踏着的每一寸土地，都有出处——脚注标明来源与页码，点击便跳到 PDF 原文对应的那一页。翻不到，它宁可闭嘴，也不胡乱编造。

**主持人**：这就解决了“幻觉”问题。但很多用户担心，库空着的时候，AI 是不是就废了？

**嘉宾**：库空着，什么系统都只会礼貌地拒绝你——这反而是好事。易知能不能成为你的那套，取决于你是否愿意把材料真正喂进去，并逼自己用“有出处”的标准验收回答。库会不会长厚，第二天打开就知道。它不是零配置秒变百科全书，而是本地库加云端推理的分工。

**主持人**：除了问答，易知在“产出”方面有什么特别的设计？

**嘉宾**：很多知识库产品停在“问完就结束”。易知把出口做宽。首先是写文章，多体例产出，可定稿入库、导出 Word。其次是播客音频，写出对话脚本后，按主持人/嘉宾双音色做 TTS，合并成完整音频。适合把复盘变成通勤可听的材料。

**主持人**：这个播客功能挺有意思，不用专门录音软件了。那“推演”又是什么概念？

**嘉宾**：推演是基于本地库推可能走向，结论要求有依据。它不是占卜，是把“如果继续按这条线走”钉在证据上。结果分四层：已知事实、可能走向、关键不确定因素、库内缺口。关系图帮你看见假设之间怎么连。

**主持人**：听起来很严谨。那它跟“自己搭一套”方案，比如 Ollama 加向量库，差在哪？

**嘉宾**：自己拼能跑通 Demo，但维护成本在半年后才露面：分块策略、冲突提示、会话记忆、归档规则、TTS、授权、安装包体积……每一项都可能变成周末加班。易知选择本地优先，数据与索引在你机器上，LLM 走可配置的 OpenAI 兼容接口。你换模型供应商，不必换知识库形态。

**主持人**：也就是说，它把那些琐碎的工程问题都打包解决了。那它适合谁用？

**嘉宾**：个人或小团队，资料以文档/网页为主，要私有、要可复查。已经在用 Markdown/Wiki 思路，但缺可信问答和回写回路。需要同一套库同时出文章、推演笔记、播客音频、任务书。愿意配 API Key，接受“本地库 + 云端推理”的分工。

**主持人**：最后，易知怎么体现“自我进化”？

**嘉宾**：记忆与进化面板跟踪规则、会话、审计。优质问答可自动归档到笔记。Loop Engineering 会扫 inbox 和草稿缺口。规则、问答、归档三股线变厚，库才像在跟你一起干活，而不是静态仓库。你问了一个好问题，得到有依据的回答，系统自动将这份问答归入笔记。下次搜同类问题，除了旧 PDF，还能翻出你上次确认过的答案。

**主持人**：所以，它不是魔法，是日积月累的功夫。

**嘉宾**：对。资料在本地，规则在你手里。易知是给资料囤积党、被幻觉伤过的人留的一扇后门。

## 待人工确认

| 确认项 | 说明 | 备注 |
| :--- | :--- | :--- |
| 启动方式 | 双击 `启动易知.bat` 或 `yws gui` | 需确认用户当前版本是否仍保留此启动脚本 |
| 命令行指令 | `yws ask` / `yws produce` / `yws skill list` | 需确认 CLI 命令是否已完全稳定 |
| 外联目录 | 只读挂进检索，不必复制文件 | 需确认是否支持所有文件类型的外联 |
| 推演四层结构 | 已知事实、可能走向、关键不确定因素、库内缺口 | 需确认推演输出格式是否固定为这四层 |
| 播客 TTS | 主持人/嘉宾双音色 | 需确认是否支持自定义音色或仅内置音色 |
| 适用人群 | 个人/小团队，资料以文档/网页为主 | 需确认是否明确排除大型结构化数据库用户 |
