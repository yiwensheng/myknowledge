# 授权服运营台 — 最短发布步骤

> 目标：把本机 `e:\app\Myknowledge\license-server` 的渠道落库 + `/admin/ui` 发布到  
> `https://www.yzwhysxx.cn/license`（NSSM：`YizhiLicense`，目录通常 `C:\yizhi\license-server`）。

**不要改线上 `.env` 密钥**；本次只需同步代码并重启。

---

## 1. 发布前（开发机）

确认这些路径存在：

```text
license-server/app/db.py
license-server/app/main.py
license-server/app/stats.py
license-server/app/static/admin/index.html
```

可选：打包待拷文件（在开发机）：

```powershell
cd E:\app\Myknowledge
$stamp = Get-Date -Format "yyyyMMdd-HHmm"
$out = "E:\app\Myknowledge\dist\license-server-admin-$stamp.zip"
Compress-Archive -Path "license-server\app","license-server\README.md" `
  -DestinationPath $out -Force
Write-Host $out
```

---

## 2. 服务器上备份

在 **Windows 授权服** 以管理员 PowerShell：

```powershell
$root = "C:\yizhi\license-server"
$bak  = "C:\yizhi\backup\license-server-" + (Get-Date -Format "yyyyMMdd-HHmm")
New-Item -ItemType Directory -Force -Path $bak | Out-Null
Copy-Item "$root\license.db" "$bak\license.db" -ErrorAction SilentlyContinue
Copy-Item "$root\app" "$bak\app" -Recurse -Force
Write-Host "Backup: $bak"
```

---

## 3. 同步代码（二选一）

### A. 整目录覆盖 `app`（推荐）

把开发机上的 `license-server\app\` **整夹复制**到服务器：

```text
C:\yizhi\license-server\app\
```

务必包含新目录：

```text
C:\yizhi\license-server\app\static\admin\index.html
```

**不要覆盖** 服务器上的：

- `C:\yizhi\license-server\.env`
- `C:\yizhi\license-server\license.db`

### B. 只拷变更文件

```text
app\db.py
app\main.py
app\stats.py
app\static\admin\index.html   （及 static\admin 目录）
```

---

## 4. 重启服务

```powershell
# 路径按你机实际 NSSM 安装调整
C:\tools\nssm\win64\nssm.exe restart YizhiLicense
Start-Sleep -Seconds 3
C:\tools\nssm\win64\nssm.exe status YizhiLicense
curl http://127.0.0.1:18888/health
```

首次启动会自动：`orders.channel_code` 列、`promoters` 表、预置张文波/胡家兵。

若启动失败：

```powershell
Get-Content C:\yizhi\license-server\stderr.log -Tail 40
```

---

## 5. 验收

```powershell
# 本机
curl http://127.0.0.1:18888/admin/ui

# 公网（浏览器打开更直观）
# https://www.yzwhysxx.cn/license/admin/ui
```

```powershell
# 用 LICENSE_ADMIN_KEY 测统计（把 KEY 换成服务器 .env 里的值）
curl "http://127.0.0.1:18888/admin/stats?admin_key=你的KEY&period=month"
```

浏览器：

1. 打开 `https://www.yzwhysxx.cn/license/admin/ui`
2. 输入 `LICENSE_ADMIN_KEY` 登录
3. 总览应能看到「易知 / 周易」分列（可无订单，但页面要出来）
4. 「渠道对账」里应能看到推广人 `P_ZHANGWENBO` / `P_HUJIABING`（或在维护区已预置）

## 6. 回滚（如有问题）

```powershell
C:\tools\nssm\win64\nssm.exe stop YizhiLicense
# 把第 2 步备份的 app 拷回 C:\yizhi\license-server\app
# license.db 一般不必回滚（仅多了列/表，兼容旧逻辑）
C:\tools\nssm\win64\nssm.exe start YizhiLicense
```

## 常见坑

| 现象 | 处理 |
|------|------|
| 公网 `/admin/ui` 404，本机 18888 正常 | 查 IIS 反代是否把路径转到 `127.0.0.1:18888`；确认已重启 NSSM |
| 403 invalid admin key | 用的是服务器 `.env` 的 `LICENSE_ADMIN_KEY`，不是 JWT |
| 页面空白 / JS 报错 | 确认 `static\admin\index.html` 已拷到服务器 |
| 旧订单没有渠道 | 正常；只有新下单且客户端带了 `channel_code` 才会有 |
