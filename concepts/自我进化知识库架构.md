# 自我进化知识库架构

## 定义

以纯 Markdown + YAML 构成的个人 wiki，AI 策展 + 本地 RAG，支持 GUI（yws gui）与命令行（yws ask）。

## 核心要点

- inbox 低门槛收集
- 五类分治 + 六张索引
- `.rag/chunks.json` 自动重建
- 文件放入目录即触发 RAG（GUI 监视 / yws watch）
