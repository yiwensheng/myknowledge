# 易知订阅授权 · 运营说明

## 架构

- **授权服务**（`license-server/`）：部署在你的 VPS，处理支付、发证、绑机
- **易知客户端**：用户电脑，启动时校验 `.license/state.json`

用户知识库内容**不会**上传到授权服务器。

## 首次部署清单

1. 云主机安装 Python 3.10+，开放 443（Nginx 反代到 18888）
2. 复制 `license-server/.env.example` → `.env`，设置：
   - `LICENSE_JWT_SECRET`（长随机串）
   - `LICENSE_ADMIN_KEY`（管理用）
   - 虎皮椒 `XUNHUPAY_*` 与公网 `XUNHUPAY_NOTIFY_URL`
3. 运行 `scripts/run-license-server.bat` 或 `python -m app.main`（生产建议 systemd + Nginx）
4. 分发给用户的易知 `.env` 写入：
   - `MYKNOWLEDGE_LICENSE_SERVER`
   - `MYKNOWLEDGE_LICENSE_JWT_SECRET`（与服务器相同）
   - `MYKNOWLEDGE_LICENSE_REQUIRED=1`

## 用户激活流程

1. 打开易知 → 弹出「激活易知」
2. 选择月付/年付 → 扫码支付
3. 支付成功自动解锁；或输入你发放的激活码

## 常见问题

| 情况 | 处理 |
|------|------|
| 换电脑 | 管理端 `POST /admin/unbind` 解绑；或用户自助 `POST /license/self-unbind`（每年 1 次） |
| 已付款未解锁 | 查 `license.db` 订单状态；必要时 `admin/mark-paid` |
| 超过 7 天未联网 | 用户联网打开易知即可恢复 heartbeat |
| 订阅到期 | 用户在激活页再次扫码续费 |

## 开发联调

1. 授权服务不设虎皮椒，保持 `LICENSE_DEV_MOCK_PAY=1`
2. 客户端 `.env` 增加（可选）：
   ```env
   MYKNOWLEDGE_LICENSE_SERVER=http://127.0.0.1:18888
   MYKNOWLEDGE_LICENSE_JWT_SECRET=与服务器相同
   MYKNOWLEDGE_LICENSE_REQUIRED=1
   MYKNOWLEDGE_LICENSE_ADMIN_KEY=dev-admin
   ```
3. 创建订单后点 GUI「模拟支付（开发）」或 `python scripts/license_admin.py mark-paid <order_id>`

## 管理 CLI

```powershell
cd Myknowledge
python scripts/license_admin.py health
python scripts/license_admin.py plans
python scripts/license_admin.py stats --db C:\yizhi\license-server\license.db
python scripts/license_admin.py export-csv --split C:\yizhi\exports\today --db C:\yizhi\license-server\license.db
python scripts/license_admin.py mark-paid <order_id>
python scripts/license_admin.py unbind --license-id <id>
python scripts/license_admin.py create-code year
python scripts/license_admin.py create-code lifetime
```

订阅分类、收入按日/周/月/季/年、活跃设备统计详见 [docs/commercial/授权统计与报表.md](commercial/授权统计与报表.md)。

环境变量 `MYKNOWLEDGE_LICENSE_SERVER`、`LICENSE_ADMIN_KEY` 可替代 `--server` / `--admin-key`。

## 安全提示

- **切勿**将 `LICENSE_JWT_SECRET`、虎皮椒密钥、`LICENSE_ADMIN_KEY` 打入用户安装包
- 客户端只配置 `MYKNOWLEDGE_LICENSE_JWT_SECRET` 用于验签（与服务器相同属正常）
- 纯客户端无法 100% 防破解；本方案面向 honest 用户与一机一码

详细 API 见 [license-server/README.md](license-server/README.md)。
